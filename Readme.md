## 🎯 Selección de proyectos

### [🍔 deli-hots](https://github.com/14BryanEspinoza/deli-hots)

Landing y pedidos online de un restaurante: catálogo desde una API REST, carrusel interactivo en React y build estático con Astro.

**💡 Lo que aprendí**

- **Islas de React en Astro** — hidratación selectiva: JavaScript solo donde hay interacción, cero JS de más
- **Consumo de API REST** — catálogo asíncrono con datos externos y View Transitions entre páginas
- **Tailwind v4 CSS-first** — design tokens con `@theme` en CSS, sin config JS
- **CI/CD** — GitHub Actions desplegando a GitHub Pages en cada push a `main`

## ⚡ Cómo trabajo

- **Mobile-first** — diseño pensado primero para la pantalla que el usuario realmente usa.
- **Accesibilidad** — HTML semántico y WCAG AA desde el diseño, no como parche final.
- **Calidad de código** — TypeScript strict, ESLint y Prettier; Husky + lint-staged ejecutan lint y format en cada commit.
- **CI/CD** — GitHub Actions despliega automáticamente a GitHub Pages en cada push a `main`.
- **Código que se lee** — estructura por componentes, commits atómicos y README en cada proyecto.
